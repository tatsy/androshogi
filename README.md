# AndroShogi

[![Android CI](https://github.com/tatsy/androshogi/actions/workflows/android.yml/badge.svg)](https://github.com/tatsy/androshogi/actions/workflows/android.yml)
[![License: GPL v3](https://img.shields.io/badge/License-GPL%20v3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)
[![GitHub Release](https://img.shields.io/github/v/release/tatsy/androshogi?color=blue)](https://github.com/tatsy/androshogi/releases)

AndroShogi は、やねうら王 NNUE を使って将棋の棋譜を検討する Android アプリです。
棋譜を読み込み、候補手・読み筋・評価値を確認したり、別の手順を分岐として検討したりできます。

**v0.2.0 のリリース準備中です。** 公開済みの最新版は v0.1.0 です。
以下は v0.2.0 に向けた `dev` ブランチの機能と使い方です。

## インストール

Android 10 以上に対応しています。
[Releases](https://github.com/tatsy/androshogi/releases) から、端末に合う APK をダウンロードしてください。

| APK の末尾 | 対象 |
| --- | --- |
| `arm64-v8a.apk` | 一般的な ARM64 の Android 端末 |
| `x86_64.apk` | x86_64 の端末・エミュレーター |

Google Play ストアを経由しないため、端末の「不明なアプリのインストール」を許可する必要があります。

## 主な機能

- 盤面操作、合法手の表示、成り／不成の選択、持ち駒の打ち込み、盤の上下反転
- KIF 棋譜の読み込み・保存・コピー・共有。各手のコメント・消費時間、駒落ちや盤面図の開始局面に対応
- 局面ごとの検討と棋譜の自動解析。候補手の矢印、読み筋、評価値、勝率グラフを表示
- 棋譜解析の開始時に、1局面あたりの秒数・候補数（MultiPV、1〜5）・開始位置を指定
- 分岐の追加・選択・本譜への復帰。分岐ごとに解析結果を保持
- コメントの閲覧とコピー、棋譜一覧、棋譜・分岐・解析結果の自動保存と復元
- 3種類の NNUE 構造に対応するエンジンの切り替え
- 思考時間・候補数・スレッド数・ハッシュサイズ・評価値表示・勝率換算・テーマの設定

## 評価関数の準備

APK には思考エンジンを同梱していますが、評価関数 `nn.bin` は含みません。
評価関数がなくても棋譜の閲覧や盤面操作はできます。検討・棋譜解析には、別途 `nn.bin` を用意してください。
入手先と利用条件は各配布元で確認してください。

1. [やねうら王の公式インストール手順](https://github.com/yaneurao/YaneuraOu/wiki/%E3%82%84%E3%81%AD%E3%81%86%E3%82%89%E7%8E%8B%E3%81%AE%E3%82%A4%E3%83%B3%E3%82%B9%E3%83%88%E3%83%BC%E3%83%AB%E6%89%8B%E9%A0%86)などから評価関数を入手し、配布物から展開した `nn.bin` を端末に保存します。
2. 「設定 → エンジン → エンジンの種類」で、評価関数に対応する NNUE 構造を選びます。
3. 「評価関数ファイル（nn.bin）」でファイルを選択し、取り込みの完了を待ちます。
4. `FV_SCALE` を配布元の案内に合わせて設定し、メイン画面に戻ります。

| 評価関数の例 | 選択する NNUE 構造 | FV_SCALE の設定目安 |
| --- | --- | --- |
| [Háo](https://github.com/nodchip/tanuki-/releases/tag/tanuki-.halfkp_256x2-32-32.2023-05-08) | `halfkp_256x2_32_32` | 20 |
| [水匠5](https://github.com/yaneurao/YaneuraOu/releases/tag/suisho5) | `halfkp_256x2_32_32` | 24 |
| 振電3 | `halfkp_512x2_8_64` | 40 |
| [AobaNNUE](https://github.com/yssaya/AobaNNUE/releases) | `halfkp_768x2_16_64` | 40 |

256構造の初期値は16、512・768構造は40です。配布元の指定がある場合はそちらを優先してください。
評価関数と `FV_SCALE` は**NNUE 構造ごとに1組**保持します。
Háo と水匠5など、同じ構造の評価関数を取り込むと、その構造のファイルが置き換わります。
v0.1.0 で設定した評価関数と `FV_SCALE` は256構造用として引き継ぎます。

構造や評価関数を変更してメイン画面に戻ると、実行中の検討・解析を終了してエンジンを再起動します。
保存済みの解析結果は保持します。

## 棋譜の読み込みと検討

メニューから KIF ファイルを開くか、クリップボードの棋譜を貼り付けます。
他のアプリから共有された KIF テキスト・ファイルも読み込めます。
「検討」は現在の局面を探索し、「棋譜解析」は指定した開始位置から選択中の手順を解析します。
棋譜解析の候補数は通常の「検討」と別に保持し、次回の解析開始時に前回の値を表示します。

途中で元の棋譜と異なる手を指すと、元の手順を残して分岐を作ります。
棋譜リストの「分岐あり」の局面へ戻り、「分岐を選択」で次の手を選びます。
分岐点では、選択中の手を青、ほかの手を緑の矢印で表示します。
「本譜に戻る」は、本譜と分岐の最後の共通局面へ戻ります。

## KIF の保存

「KIF ファイルを保存」で、`.kif`（Shift_JIS）か `.kifu`（UTF-8）を選びます。
初回は Documents/AndroShogi などの保存先フォルダーを選択します。
次回からその場所を保存画面の初期位置として指定しますが、端末のファイル選択画面によっては反映されない場合があります。

保存時に「解析結果をコメントに含める」を選ぶと、各局面の全候補の評価値・探索深さ・保存済みの読み筋を追記します。
初期状態はオフです。評価値は先手基準で、例えば1手目後の局面では次の形式になります。

```text
*元のコメント
*[AndroShogi解析] 1手目後（評価値は先手基準）
*候補1：評価値 +320 / 深さ 20
*読み筋1：△３四歩 ▲２六歩 △８四歩
```

元のコメントはそのまま残します。再読み込みした解析コメントは通常のコメントとして扱い、検出・置換・重複除去は行いません。
その棋譜を再解析して解析結果付きで保存すると、既存コメントの末尾へ再度追記します。

KIF の読み込みは一本の手順、保存・コピー・共有は選択中の手順だけが対象です。
分岐を含む棋譜全体はアプリ内に自動保存されます。
コメントの編集、KI2・CSA の読み込み、分岐を保持する KIF 入出力には対応していません。
